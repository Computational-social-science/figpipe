03Capability evidence: style transfer really changes pixels

Style distance of the eight compliant variants; orange is the best. Combining the three factors lowers the seed Fig. 7 distance from 0.122 to 0.093 (improvement 0.029).

Why this is a capability, not a claim: on the first run, the styled and plain figures had exactly the same distance (Δ=0): the default height overrode the reference aspect, and the palette never reached the histogram/box draw parameters. Only after that fix did the same tasks improve. "Looking like transfer" and "changing pixels" are different things.

Deciding beats always transferring. Over the 141 tasks measured with the decision in place, the shipped figure averages 0.292 style distance, versus 0.309 for always-styled and 0.377 for never styling. The decision picked the styled candidate 132 times and the plain one 9 times, using only the reference (an input, not the answer key).
Official code channel (style inferred from the reference IMAGE): 75.41 / 100 over 149 tasks (min 0.0, max 100.0). This is the benchmark's own deterministic channel deviation-defect-v1, worth 35% of the official score; the remaining 65% is a vision channel this project does not run, so no combined score is claimed. Style is inferred from the reference picture — the benchmark's actual premise — not from its code. Baseline (matplotlib defaults with the compliance floor): 38.16, so the pipeline is +37.25 points (97.6% relative) better than doing nothing beyond compliance. For comparison, extracting the style from the shipped reference_code scores 100.0 — that is a ceiling, not a capability: the task record contains the reference code, so copying its features scores 100 by construction.
Measurement freshness: 141 of 141 executed tasks were measured with the current rendering code (fingerprint 6f01bca5b70f), 0 with an earlier version, and 0 before the fingerprint was recorded — those are unknown, not stale. Re-measure a chart type with --types X --scan after a change to the shared style/layout layer; a stale row can make a fix look like a regression.
A style metric cannot see a wrong number. Every figure is now also checked by figpipe/semantics.py: the printed r must match the data's r, no drawn point may fall outside the axes, and the axis labels must be the ones the panel claims. Semantic violations in this run: 0.
